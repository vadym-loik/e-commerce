# E-commerce Project

This is a simple e-commerce web application that allows users to view products and manage their shopping cart.

## Project Structure

- **index.html**: The main entry point of the application. It contains the basic structure of the webpage and links to the CSS and JavaScript files.
- **products.html**: This page displays the available products for users to browse.
- **cart.html**: This page allows users to view items they have added to their shopping cart.
- **styles.css**: This file contains the styles for the entire application, defining the appearance of HTML elements across all pages.
- **script.js**: This file contains the JavaScript code that handles interactivity and functionality for all pages.
- **README.md**: This documentation file provides an overview of the application and setup instructions.

## Setup Instructions

1. Clone the repository or download the project files.
2. Open the `index.html` file in a web browser to view the application.
3. Navigate between pages using the links provided in the header of each page.

## Navigation

- From **index.html**, you can navigate to:
  - [Products](products.html)
  - [Cart](cart.html)

- From **products.html**, you can navigate to:
  - [Home](index.html)
  - [Cart](cart.html)

- From **cart.html**, you can navigate to:
  - [Home](index.html)
  - [Products](products.html)

Feel free to customize the styles and scripts to enhance the functionality and appearance of the application!
